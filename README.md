# VR-химлаборатория

Учебный VR-проект по химии на **Unreal Engine 5.8.4** для **Meta Quest**.

- Основа: OpenXR.
- Главная карта: `Content/XRFramework/Levels/L_XRTemplate`.
- Сейчас: прототип лабораторной станции; механика смешивания в разработке.

## Запуск

Открой `Lab1.uproject` в UE 5.8.4 и запусти сцену через **VR Preview**.
